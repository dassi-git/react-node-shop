# UI & Design Standards - Project Alpha

## General Rules
* All interface components must support Right-to-Left (RTL) alignment.
* Main Theme Color: #2E5BFF (Royal Blue).
* Font: 'Assistant', sans-serif.

## RTL Guidelines
* Padding and margins must use logical properties (e.g., margin-inline-start instead of margin-left).
* Icons that indicate direction (like arrows) must be mirrored.
