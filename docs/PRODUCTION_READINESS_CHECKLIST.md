# רשימת בדיקות לפני עלייה לאוויר

מטרת המסמך היא לוודא שמערכת הזמנות עיצובי הפירות מוכנה לשימוש אמיתי. יש לסמן כל סעיף רק לאחר שבוצע ונבדק בסביבת staging הדומה לייצור.

## 1. הכנת סביבה ופריסה

- [ ] קיימת סביבת `production` נפרדת מסביבת `development`.
- [ ] השרת עולה ללא שימוש ב־MongoDB בזיכרון.
- [ ] `DATABASE_URI` מצביע למסד נתונים מנוהל ומאובטח.
- [ ] מוגדר `NODE_ENV=production`.
- [ ] מוגדר `PORT` דרך משתנה סביבה.
- [ ] מוגדר `CLIENT_URL` לכתובת האתר האמיתית.
- [ ] מוגדר דומיין עם HTTPS פעיל.
- [ ] ה־Frontend משתמש בכתובת API של production ולא ב־localhost.
- [ ] אין סודות בקוד, ב־Git או בקבצי build.
- [ ] קבצי `.env` אינם מועלים ל־GitHub.
- [ ] קיימת תצורת CORS שמאפשרת רק את דומייני האתר.
- [ ] נבדקה פריסה נקייה על שרת חדש.
- [ ] קיימת תוכנית rollback לגרסה הקודמת.
